# test/golden — ゴールデン基準（UI参照画像）

このディレクトリの中身は**検証の正解**である。参照オラクル
（`verification/reference/`）と同じ扱いをする。

## 規則（CLAUDE.md §3.5-10 / §5・PROCESS.md §5-12）

- **初回生成も、既存の更新も、人間ゲート。** エージェントは基準を生成しない。
  検証の正解を、検証される側が作ってはならない。
- 基準が無いテストに当たったエージェントは、**ISSUE 起票 → blocked** とし、
  次のタスクへ移る（生成して先へ進んではならない）。
- 更新は人間の明示指示（`--update-goldens` 相当）のみ。更新前後の差分は
  人間がレビューする。
- このディレクトリは `protected.paths`（`test/golden/**`）に含まれており、
  `Agent:` トレーラ付きコミットによる変更はゲートが赤にする。

## 基準の入れ方（人間）

1. 実装を人間が実機で確認する
2. 基準画像を生成し、このディレクトリへコミットする（`Agent:` トレーラを付けない）
3. 対応するテストが基準と比較することを確認する

基準が入るまで、該当テストは skip ではなく **blocked のタスク**として扱う。
skip にすると「未装備」が緑に混ざる。
